# Virtual Football Manager Career

A complete browser-based football management simulation game built with Next.js, Firebase, and Three.js.

## 🎮 Features

- **Career Mode**: Create your manager, choose a club, and build your legacy
- **Match Engine**: Realistic football simulation with Three.js 3D visualization
- **Transfer Market**: Buy, sell, loan, and negotiate contracts
- **Training System**: Develop players through daily and weekly training
- **Tactics**: Customize formations, playing style, and instructions
- **Financial Management**: Manage budgets, salaries, sponsors, and merchandise
- **Player Development**: Track player growth, potential, and statistics
- **Achievements**: Unlock rewards for career milestones
- **News System**: Dynamic football news and updates
- **Responsive Design**: Works on all devices with dark glassmorphism theme
